#### 注音体系

- `pronunciation` 列默认是国际音标（`q3` 已用 `--ipa-only` 去掉原表括号里的拼音附注）。
- `u3` 的「代表音」是彝语拼音方案，原样保存在 `pronunciation` 列；计算发音相似度时才按
  [`map/yi_pinyin_ipa.yaml`](map/yi_pinyin_ipa.yaml) 转成 IPA（见 `src/backend/services/yi_pinyin.py`）。
  该表按《通用彝文规范方案》2010 正字法（贾海霞, 沙马拉毅 2018）记录声母、韵母与声调字母的对应；
  字典里的汉语借词读音（如 `hao`、`zhui`）不属于彝语音节，转不出 IPA 时不做发音比较。
- 新增注音体系时在 `SOURCE_META` 里给该来源标 `"phonetic"`，并在 `yi_pinyin.py` 里挂对应转换即可。

#### 《彝汉字典》D1–D6 整理包

`d1`-`d6` 由 [`utils/merge_d1d6.py`](utils/merge_d1d6.py) 从整理包 XLSX 生成：

```
python utils/merge_d1d6.py <D1-D6_彝汉字典_整理.xlsx>
```

- `src_ref` 为 `{来源}-{页码:03d}{页内序号:02d}`，页内序号按书中阅读顺序逐页累加——整理表里
  原表漏收、后来补入的字头没有条号，靠这个序号接在原位（旧版 d3/d4 的条号也按同一规则对得上）。
- 第 5 列 `note` 保留整理表的「备注」。整理表的「原书截图」列没有导入。
- 这批字头的码位（`U+E000`、`U+F0000`、`U+F1000`、`U+F3000` 等）和 `font/yi.ttf` 里已有的字**冲突**
  （同一码位是另一个字），所以单独用 [`font/YiHeadwords-D1D6.otf`](font/YiHeadwords-D1D6.otf) 渲染：
  `SOURCE_META` 里给这些来源标 `"font": "yihead"`，前端 `glyphFont()`（[`src/frontend/js/ui.js`](src/frontend/js/ui.js)）
  据此只在该来源的字形上改用 `YiFontHead`，不进通用字体栈。

#### 字体的区分与使用范围

| 字体 | `SOURCE_META` 的 `font` | 用在哪些来源 | 怎么选中的 |
| --- | --- | --- | --- |
| `font/yi.ttf` | `yi` | u0–u3、q0–q3、d0、d7、d8 | 通用字体栈的第一位 |
| `font/tyht.ttf` + `tyht-extra.ttf` | `yi` | 同上，仅当 `yi.ttf` 缺字时逐字回退 | 同一个栈的后两位，由浏览器按字符回退 |
| `font/YiHeadwords-D1D6.otf` | `yihead` | d1–d6 | `glyphFont()` 给这些字形单独指定 |

- 只有 `yihead` / `yi` 这一层是「按来源」显式区分的；`yi.ttf` 与 `tyht*.ttf` 之间是逐字回退，
  前端拿不到「这个字最终由哪个文件渲染」，所以来源卡片上统一标成 `yi.ttf (+tyht)`。
- 所有会画字形的界面都走 `glyphFont()`：浏览表、字符详情、相似建议、对齐取字/当前组/关联组、
  分组表、录入表；部首标注页按来源整页设置 `--glyph-font`（`/api/radical-data/{source}` 返回 `font`），
  但右边的部首列表来自全局 `rs/rs_order.yaml`，始终用通用字体栈。
- 来源卡片和字符详情会显示「Font: …」，方便核对某个来源用的是哪套字体。
  改完 `style.css` / `ui.js` 后要强制刷新，否则浏览器会用缓存的旧样式或脚本。
