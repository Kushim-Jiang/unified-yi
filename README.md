#### 对比表 (u4)

`u4` 是四省区单字的对比表, 也归入通用源 (`group: unified`)。一行一个字头（书里描摹的正体字）,
滇/川/黔/桂四栏的异体出处和读音合在 `pronunciation` 列, 写作
`滇 ⑩18 t'v³³；④32 t'o¹¹ ｜ 川 ②53 t'u³³ ｜ …`; 出处代号（圈码、`明`、`多`）、
汉字音译和法文拼音都照录, `（无注）` 是只有字形没有注文的异体。`note` 保留原表「备注」,
原书截图没有导入, 异体字形请看整理包的 XLSX。

`u4` 由 [`utils/import_u4.py`](utils/import_u4.py) 从整理包的 XLSX 生成（同一次运行还写出 `rs/u4.tsv`）：

```
python utils/import_u4.py <U4_整理.xlsx>
```

- `src_ref` 为 `U4-{页码:03d}{页内序号:02d}`，页内序号按表中顺序逐页累加；整理表里 14 个空行已略去。
- 原表第 293 页「碗」没有填正体字，`glyph` 用 `？` 占位（同 `u3`）。
- `pronunciation` 是四省区读音的合录, 不是单个音节, 所以 `SOURCE_META` 标 `"phonetic": "comparative"`:
  不做发音相似度比较（`_char_ipa()` 返回空, 发音建议里也不会混进 `u4` 的字）。
- 原表目录里的 37 个部首字形（码位 `U+F6400`–`U+F6424`，原表没有笔画数）保存在
  `rs/u4_original.tsv`；`rs/u4.tsv` 现在和其他来源一样按 `u0` 的部首体系标注（见下方「部首」）。

### 部首

`rs/*.tsv` 全部按 `u0`（通用彝文字典）的 75 个部首（`rs/rs_order.yaml`）和部首外笔画数标注。
`u0`、`q0`、`d0` 和 `d8` 的前 605 条是原有的人工标注；其余来源是 2026-11 补的：与已标字形
同图或几乎同形的直接继承，其余由人工智能对照 `u0` 例字看图判定，**尚未逐字人工复核**，
笔画数尤其需要核对。

例外：`q1.tsv` 按原书《正体字部首检字表》标注（2026-11-26 复核）。原书 56 部，部首字用 yi.ttf 里
按原书部首目录顺序造的 `U+C1B0`–`U+C20B`（括号里的变体归入主形）；在检字表里两个部首下都收的字，
两个部首都标（逗号分隔）。原书笔画“连部首笔画一起数算”，`other_stroke` = 全字笔画 − 部首笔画
（目录里一画部首减 1，二画减 2，依此类推）；检字表是确数笔画组的照录，范围组（如“二至三画”）
和未分组的逐字数过。原书《正体字难检字表》里的字（书上不给部首）和两张表都没找到的字暂保留旧标注。

#### 注音体系

- 各本的紧元音（书中元音下加短横、钩或波浪）统一按舌根后缩写 IPA 的 ̙（U+0319），如 `pi̙³³`。
- `pronunciation` 列默认是国际音标（`q3` 已用 `--ipa-only` 去掉原表括号里的拼音附注）。
- `u3` 的「代表音」是彝语拼音方案，原样保存在 `pronunciation` 列；计算发音相似度时才按
  [`map/yi_pinyin_ipa.yaml`](map/yi_pinyin_ipa.yaml) 转成 IPA（见 `src/backend/services/yi_pinyin.py`）。
  该表按《通用彝文规范方案》2010 正字法（贾海霞, 沙马拉毅 2018）记录声母、韵母与声调字母的对应；
  字典里的汉语借词读音（如 `hao`、`zhui`）不属于彝语音节，转不出 IPA 时不做发音比较。
- 新增注音体系时在 `SOURCE_META` 里给该来源标 `"phonetic"`，并在 `yi_pinyin.py` 里挂对应转换即可。
- `d1`（楚雄本）按原书凡例给四个参考音点注音：①武定（东部纳苏）、②永仁猛虎（中部俚泼）、
  ③南华天申堂（中部罗罗泼）、④双柏安龙堡（南部聂苏）。`pronunciation` 列照书录全，每个读音后跟用这个读音的
  音点圈码，读音之间用 `/` 隔开，顺序同原书，如 `pi⁵⁵①②③/pi²¹④`；书里缺某点的就不列，方括号是书中的双音节形式。
  声调按凡例：˥ 55、次高（书中印作 Γ 形）44、˧ 33、˩ 21。比较发音时去掉圈码、只取第一个读音（一般是 ① 武定音）。
- `u0`（通用彝文字典）照书录全十三个音点：①威宁 ②石林 ③红河 ④巍山 ⑤喜德 ⑥楚雄，Ⓛ禄劝 Ⓓ大方 ⓑ毕节 Ⓟ盘县
  ⓢ石屏 ⓨ永仁 ⓖ隆林（标号照书，大小写不一）。书中标号写在读音前、每点一读；仓库里把读音相同的点合在一起，
  写成 `pi⁵⁵①②⑥ⓁⓨⓅⓑ/pi²¹③ⓢⓖ/…`，读音按首次出现的顺序。紧元音（书中元音下加钩或短横）按舌根后缩写 IPA 的 ̙（U+0319）；
  禄劝点书中印作 ç 的元音（o 下带钩，同 `u1` 的卷舌钩）暂按卷舌元音录作 o˞。
  圆括号是书中“字头前后词素”的读音（凡例三）或原注的汉字（动、量、自动、使动等），照录。
  紧元音的短横在原书中印得很淡，以未经压缩的扫描本为准核对；舌尖元音按声母统一（卷舌声母后作 ʅ，其余作 ɿ），
  a/ɑ 统一作 ɑ，m/n 下加点：后接元音作清化 ̥、单独成音节作 ̩。比较发音时去掉标号、只取第一个读音。
- `u1`（滇川黔桂彝文字典）照书录全十一个音点：①威宁 ②路南 ③红河 ④巍山 ⑤喜德 ⑥南华，Ⓛ禄劝 Ⓓ大方 ⓢ石屏 ⓨ永仁 ⓖ隆林。
  格式同 `u0`（书中标号在读音前，仓库里按读音合并音点），如 `pi⁵⁵①②⑥Ⓛⓨ/pi²¹③ⓢⓖ/…`。紧元音（书中元音下短横）写 ̙；
  书中元音下另有一种小钩（多见于禄劝点的 o，与 ʐ、ʂ 的卷舌钩同形），与短横不同、可与短横同现，录作卷舌 ˞，如 `po˞⁵⁵`。
  书中误印的标号“(k)”“ⓚ”按位置和调值作 ⓖ；读音后括号内汉字为书中原注，照录。舌尖元音、a/ɑ 的统一同 `u0`。
- `q0`（贵州本 2018 增订本）照书录全五个参考音点：①威宁板底、②大方安乐、③盘县淤泥、④威宁灼圃、⑤七星关大屯，
  格式同 `d1`，如 `pi⁵⁵①③④/pie⁵⁵②⑤`。读音取自 PDF 文字层；③ 的紧元音在版面上是字下短横，按位置识别后写 ̙。
  文字层里成音节 m 的点作“．”、ɣ 有几处编成 U+FE00，均已按版面改正。
- `q1`（贵州本 1991）同样照书录全四个参考音点：①威宁板底、②大方安乐、③盘县淤泥、④威宁灼圃，格式同 `d1`，
  如 `pi⁵⁵①③④/pie⁵⁵②`。声调按说明：˥ 55、˧ 33、13（低升）、21（低降）；③ 的紧元音（书中元音下加短横）写 ̙。
  书里不印 ① 的条目从所印的第一个音点开始；读音后没有圈码的，是说明所称“彝文古籍中的古语音”。
  扫描本分辨率很低，印刷不清的地方在 `note` 列写明；个别缺印的调号、韵母据 2018 增订本（`q0`）补，也在 `note` 说明。

#### 《彝汉字典》D1–D6 整理包

`d1`-`d6` 由 [`utils/merge_d1d6.py`](utils/merge_d1d6.py) 从整理包 XLSX 生成：

```
python utils/merge_d1d6.py <D1-D6_彝汉字典_整理.xlsx>
```

- `src_ref` 为 `{来源}-{页码:03d}{页内序号:02d}`，页内序号按书中阅读顺序逐页累加——整理表里
  原表漏收、后来补入的字头没有条号，靠这个序号接在原位（旧版 d3/d4 的条号也按同一规则对得上）。
- 第 5 列 `note` 保留整理表的「备注」。整理表的「原书截图」列没有导入。
- 这批字头的码位（`U+E000`、`U+F0000`、`U+F1000`、`U+F3000` 等）和 `font/yi.ttf` 里已有的字**冲突**
  （同一码位是另一个字），所以单独用 [`font/YiHeadwords-D1D6.otf`](font/YiHeadwords-D1D6.otf) 渲染：
  `SOURCE_META` 里给这些来源标 `"font": "yihead"`，前端 `glyphFont()`（[`src/frontend/js/ui.js`](src/frontend/js/ui.js)）
  据此只在该来源的字形上改用 `YiFontHead`，不进通用字体栈。

#### 字体的区分与使用范围

| 字体 | `SOURCE_META` 的 `font` | 用在哪些来源 | 怎么选中的 |
| --- | --- | --- | --- |
| `font/yi.ttf` | `yi` | u0–u2、q0–q3、d0、d7、d8 | 通用字体栈的第一位 |
| `font/tyht.ttf` + `tyht-extra.ttf` | `yi` | 同上，仅当 `yi.ttf` 缺字时逐字回退 | 同一个栈的后两位，由浏览器按字符回退 |
| `font/tyht.ttf` + `tyht-extra.ttf`（「通用彝文黑体」） | `tyht` | u3 | `glyphFont()` 指定，顺序为 tyht → tyht-extra → yi.ttf |
| `font/YiHeadwords-D1D6.otf` | `yihead` | d1–d6 | `glyphFont()` 给这些字形单独指定 |
| `font/YiHeadwords-U4.otf` | `yiheadu4` | u4 | 同上，`glyphFont()` 指定 |

- `u3` 的码位是按 `tyht.ttf` 编排的，其中约 3450 个在 `yi.ttf` 里是别的字，放进通用栈会被
  `yi.ttf` 抢先画错，所以单独标 `font: "tyht"`；`tyht` 两套都没有的 19 个字才回退到 `yi.ttf`。
- 只有 `yihead` / `yiheadu4` / `tyht` / `yi` 这一层是「按来源」显式区分的；`yi.ttf` 与 `tyht*.ttf` 之间是逐字回退，
  前端拿不到「这个字最终由哪个文件渲染」，所以来源卡片上统一标成 `yi.ttf (+tyht)`。
- 所有会画字形的界面都走 `glyphFont()`：浏览表、字符详情、相似建议、对齐取字/当前组/关联组、
  分组表、录入表；部首标注页按来源整页设置 `--glyph-font`（`/api/radical-data/{source}` 返回 `font`），
  但右边的部首列表来自全局 `rs/rs_order.yaml`，始终用通用字体栈。
- 来源卡片和字符详情会显示「Font: …」，方便核对某个来源用的是哪套字体。
  改完 `style.css` / `ui.js` 后要强制刷新，否则浏览器会用缓存的旧样式或脚本。
